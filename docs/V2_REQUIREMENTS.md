## 2. 标识与分类规则

- 条目 ID 形如 `V2-<域>-<nn>`，域为 `ARCH` `UX` `READER` `WRITE` `MUSIC` `DOWNLOAD` `VIDEO` `NAV` `THEME` `BRAND`。
- ID 一经发布不复用、不重排；删除需求只能改为 `OUT` 并保留行。
- 分类：`MUST`（2.0.0 必须交付）/ `SHOULD`（有则更好，允许在证据说明后延期）/ `LATER`（2.0.0 之后）/ `OUT`（明确不做）。
- 每条需求一句话、可观察、可验收；来源列指向原始文档行区间。原文中流程仪式类内容（角色设定、汇报格式、分支策略、子代理管理、工具安装清单）**不入需求**，由协作约定与任务卡承接。
