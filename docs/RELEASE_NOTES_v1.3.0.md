# 极光幕 · Aurorama 1.3.0 发布说明

> v1.2.0 之后的功能更新（2026-10-17）：18 项用户反馈（9 项修复 + 9 项需求）——音乐播放面板与队列、歌词、书籍手势与 EPUB 排版、搜索全类型与返回栈、媒体库下拉刷新与家庭视频进度。

## 关于本版本

极光幕（Aurorama）1.3.0：面向手机 / 平板的第三方原生 Jellyfin 客户端，基于 [Findroid](https://github.com/jarnedemeulemeester/findroid)（GPL-3.0，基线 `a28ac9e`）改造，以直接播放（Direct Play）为主。

包名 `io.github.zhangwenkang.aurorama`，版本 `1.3.0 (4)`，要求 **Android 9（API 28）及以上**。

## 本版亮点与修复

**音乐播放**

- **通知栏播放面板**：音乐播放时提供标准媒体通知——封面、标题、播放 / 暂停、上一曲 / 下一曲、可拖动进度，点按可回到播放页；切换播放内核后仍然可用。
- **播放队列超过 500 首**：修复队列在 64 首左右被截断的问题（根因是后台补齐中断）；随机播放覆盖完整队列，不再反复只播固定的几首。
- **1.75× 倍速**：倍速面板与设置页统档位，新增 1.75×，切换后立即生效。

**歌词**

- **三处居中**：歌词页、播放面板与悬浮窗的歌词正文统一水平居中，当前行仍保持垂直居中。
- **默认双语对照**：中 / 外文歌词默认上下两行显示；没有译文时自动回落单行；手动关闭后会记住选择。
- **字号与行距可调**：歌词页新增字号、行距档位，调整即时生效并在重启后保持；播放面板同步生效。

**音乐界面**

- **歌曲缩略图**：歌曲分类的每一行显示专辑封面（服务器专辑图 / 本地内嵌图 → 同专辑兜底 → 音符占位），序号与行高保持不变。
- **自动定位当前曲**：进入歌曲栏或切歌时，列表自动滚动到正在播放的歌曲；手动滚动时不会被强行拉回。

**阅读**

- **EPUB 滚动与双栏生效**：滚动档可以连续滚动长章，双栏档在竖屏 / 横屏下显示真正的两列。
- **阅读器手势**：PDF / CBZ 支持双击中间适宽、双击左侧上一页、双击右侧下一页、上下滑动调亮度；EPUB 对应左右翻页与亮度调节，双击中间切换单 / 双栏。
- **书籍下载反馈**：长按选择后点下载会立即给出反馈；下载页出现书籍条目、进度与完成态；阅读页发起的下载不再因离开页面而取消。

**搜索与导航**

- **搜索音乐与书籍**：搜索范围扩至影视、音乐、书籍，并按类型分区展示；结果可直达详情或播放。
- **返回保留来源页**：从首页、视频、媒体库、二级库或音乐入口进入搜索，关闭或返回到进入前的页面，不再统一跳回媒体库。

**媒体库**

- **下拉刷新**：媒体库总览支持下拉刷新，刷新时保留旧内容、不闪烁；重复下拉或切换页面不会误触发。
- **家庭视频进度条**：家庭视频缩略图显示与续播一致的观看进度；已看完的条目不显示进度线。

## 安装与升级

从 [GitHub Releases](https://github.com/zhangwenkang-github/Aurorama/releases) 下载签名 APK，直接安装（首次安装需允许「安装未知应用」）。**1.2.0 / 1.1.0 / 1.0.0 可直接覆盖安装**，数据与登录态保留。

| 下载文件 | 面向 | 建议 |
|----------|------|------|
| `Aurorama-1.3.0-universal.apk` | 全部 ABI（armeabi-v7a / arm64-v8a / x86 / x86_64） | 不确定机型 / 兼容性优先 |
| `Aurorama-1.3.0-arm64-v8a.apk` | 仅 arm64-v8a | 2017 年后的主流 64 位手机 / 平板（体积约为整包一半） |

> 两个包内容一致、同为 release 签名；**同一设备上请始终用同一签名的包升级**（换签名无法覆盖安装）。调试包（`.debug` 后缀）可与正式包共存、数据互相独立。各包体积与 SHA-256 见 `docs/RELEASE_PLAN.md` §7。

## 已知限制

- **远端 PDF 仍需整本下载后打开**（打开过程可看到下载进度）；PDF 按需加载 / 渲染引擎替换列入后续版本计划；
- 阅读流式加载需要网络连接；离线阅读请先「下载整本」；
- **MIUI（小米 / Redmi）**：系统媒体面板不显示本应用自定义的「关闭」键（系统面板行为限制），可用面板内其它控制键或回到应用内关闭；
- 直接播放优先：服务器端不支持直放的片源会静默转为 HLS（画质 / 音轨以服务器转码设置为准）；硬解与服务器转码都不成功时自动降级 libmpv 软解，功耗与发热更高；
- 本地媒体库受 Android 存储限制：无法选择 `Android/data`、`Android/obb`、其它应用私有目录；
- TV（遥控器 / D-pad）界面未适配，仍面向手机与平板；
- 仅做 GitHub Releases 分发，暂无国内商店 / Google Play 渠道。
