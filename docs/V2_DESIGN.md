# Aurorama 2.0 设计方向（DESIGN 纲领）

> 状态：W0 定稿（2026-11-18）　分支：`codex/v2-integration`
> 本文档定义 2.0 视觉方向与主题体系；token 数值在 W1 设计系统落地时校准并回写。
> 既有资产：`docs/design/v2-theme-frames/`（五主题主页框架稿）、`docs/design/v2-logo-redesign/`（三个 logo 方向 SVG+proof）、ADR-0007（部分被本文件取代）。

## 1. 与历史决策的关系

ADR-0007（2026-11-02）保留有效的部分：主题是覆盖全 App 的完整视觉身份；主题共享信息架构/导航/组件行为/交互语义；明暗、内容域语义、阅读正文偏好、系统动态色为正交维度；WCAG AA 与减少动画基线；产品 UI 字重只用 400/500/700；4/8 网格。

**被 2026-11-18 用户新指令取代的部分**：
- 默认主题 ~~Lumen~~ → **极光（Aurora）**。
- logo ~~沿用 W38 旧极光帘幕图标~~ → **重设计**（含 adaptive icon 分层 + monochrome）。
- 界面图标 ~~只重绘低对比/歧义/高频~~ → **图标体系全部重设计**（统一栅格与光学尺寸）。
- 组件布局全部重新设计。

## 2. 主题体系

| 主题 | 定位 | 变体 |
|---|---|---|
| **Aurora（极光）= 默认** | 品牌主主题：深夜天幕底色 + 极光渐变点缀（青→绿→紫的窄光谱流动感，只用于强调色/焦点态/品牌资产，不大面积铺背景） | 深色为主 |
| Light（浅色） | 近白底 + 同一极光强调色 | 浅色 |
| AMOLED | 纯黑 #000 底，OLED 节电，强调色同 Aurora | 深色 |
| 系统动态色 | 壁纸取色，独立主题不叠加品牌 | 随系统 |

- 切换即时生效、持久化；新装默认 Aurora，升级用户保留显式选择，未显式选择过的旧用户进入 Aurora。
- 既有 Prism / Nocturne / Monolith 框架稿保留为后续可选主题（LATER，不进 2.0.0 发布门）。
- 阅读器正文 4 套显示主题（日间/夜间/护眼/纯黑）保留为阅读域子主题，外框服从 App 主题。

## 3. 主题定稿：K1 Aurora Cinema（2026-11-18 用户验收通过）

**用户已批准 K1 方向稿**（`docs/design/k1-aurora/`：phone-home / phone-detail / phone-music / tablet-home / icon-a / icon-b）。以下 token 为定稿值，W1 实现不得偏离。

### 3.1 色彩 token（深色 Aurora 默认）

| Token | 值 | 用途 |
|---|---|---|
| `bg0` | `#04070D` | 屏幕最底层 |
| `bg1` | `#080D17` | 页面底 |
| `bg2` | `#0D1522` | 浮层/卡片 |
| `bg3` | `#131D30` | 按压/更高层 |
| `textPrimary` | `#F5F7FB` | 主文字 |
| `textSecondary` | `#9FAEC4` | 次文字 |
| `textFaint` | `#5D6C85` | 弱文字 |
| `aurora1/2/3` | `#3DE8C2` / `#6FA0FF` / `#B07CFF` | 极光渐变三段（青→蓝→紫） |
| `auroraGradient` | 100° 线性渐变 au1→au2→au3 | 主 CTA、进度、选中态、焦点环 |
| `auroraGlow` | `0 6px 28px rgba(61,232,194,.28)` 级 | 主 CTA/焦点投影 |
| `glass` | `rgba(10,16,28,.58)` + blur 28–30 | 悬浮导航/迷你播放器/顶栏 |
| `glassBorder` | `rgba(255,255,255,.09)` | 玻璃描边 |

规则：渐变只允许出现在主 CTA、进度、选中/焦点态、logo 与品牌页；页面背景禁大面积渐变（环境光晕例外，且必须来自当前内容图）。前景文字 onAurora = `#04201A`。

### 3.2 形状 / 动效 / 排版 token

- 圆角：海报 14、卡片 20、按钮 16、玻璃容器 32–44、logo 容器 26–150（按尺寸比例）；同页不混用两套圆角体系。
- 动效：150–300ms，弹簧可中断，尊重 Reduce Motion；容器开合 180–220ms。
- 字体：MiSans/Noto Sans SC 族；字重 400/500/700；字阶 13/15/18/24/32/44（手机基准）；行高 1.5–1.6。

### 3.3 覆盖范围（用户 2026-11-18 明确要求）

主题必须覆盖**全部**界面：首页/库/详情/搜索/设置/下载中心、**视频播放页**（控制层玻璃、进度、手势 HUD、错误卡）、**音乐界面**（迷你播放器、全屏播放页、队列、歌词）、**阅读器外框**（正文显示仍由阅读域 4 套子主题覆盖）。浅色 Light 与 AMOLED 变体在 W1 以同一 token 结构派生（Light：近白底 + 同极光强调；AMOLED：`bg0/bg1 = #000`）。

### 3.4 Logo 定稿

- **采用 B「极幕之眼」**（`docs/design/k1-aurora/icon-b.png`，SVG 源在 `_src/direction-k1.html` 的 `icon-b` 段）：极光渐变光圈 + 切口光束 + 极星。
- A「极光帘幕」保留为备选资产，不删除。
- W1 任务：B 定稿派生 adaptive icon（前景/背景分层 + monochrome），修正 mipmap 目录 `-v26` 命名。

## 4. 品牌与图标路线

- **Logo**：已定稿 B「极幕之眼」（见 §3.4）。A 保留备选。
- **界面图标**：96 个既有自定义 vector 逐批重绘，统一 24dp 栅格、2dp 笔宽（W1 定 token）、圆角端点；消灭图标内写死 fillColor（75 个现状）。图标造型规范由 Kimi 出 SVG 样张，deepseek 按样张批量执行。
- **布局**：以 K1 稿为准——首页为整体构图（Hero + 货架）而非卡片堆叠；一区块一主功能；高频操作下沉拇指区；宽屏左玻璃侧栏 + 内容 + 底部播放条。

## 5. W1 设计系统落地清单（实施波任务卡依据）

> **执行约束**：设计决策（token 数值、配色、logo 选型、布局方案）由主负责人 Kimi 亲自制定并定稿进本文件；deepseek 子代理只按定稿做代码实现，不做任何样式自由发挥。

1. 主题引擎：`CinefinTheme(themeId)` + palette 注册表；打通 `darkTheme` 与 `pref_theme`；Lumen 皮肤机制并入。
2. Aurora/Light/AMOLED/Dynamic 四套 token 集（颜色/排版/形状/间距/动效强度）。
3. Logo 定稿派生资源（mipmap-anydpi 修正 `-v26` 命名）；图标第一批（导航/播放传输/高频动作约 30 个）。
4. 核心组件换肤验证屏：首页/库/详情/播放器壳/Mini Player/设置。
5. 验收：四主题切换即时生效无残留色；7 态抽查；对比度 AA。
