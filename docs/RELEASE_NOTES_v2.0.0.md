# 极光幕 · Aurorama 2.0.0 发布说明

> 2.0 大版本（2026-11-24）：W0–W9 十个波次整体交付——全新 Lumen 深色影院设计体系、下载引擎重写、离线能力补齐、音乐/阅读/搜索全线增强，以及 40+ 项旧缺陷清扫。

## 关于本版本

极光幕（Aurorama）2.0.0：面向手机 / 平板的第三方原生 Jellyfin 客户端，基于 [Findroid](https://github.com/jarnedemeulemeester/findroid)（GPL-3.0）改造，以直接播放（Direct Play）为主。

包名 `io.github.zhangwenkang.aurorama`，版本 `2.0.0 (7)`，要求 **Android 9（API 28）及以上**。

## 本版亮点

**全新设计体系（Lumen）**

- 深色影院风全面重构：统一设计 token、8pt 网格、统一圆角与动效规格，全部组件去硬编码。
- 主题三档：极光（aurora）/ 纯黑 AMOLED / 动态取色，深浅色正交切换，中文 / 英文 / 繁中三语文案。

**播放**

- 三内核编排：ExoPlayer 硬解 → FFmpeg 软解 → libmpv 兜底，坏流自动回退；播放进度跨内核无缝续播。
- 手势体系：亮度 / 音量 / 进度手势统一规格；字幕 / 音轨语言智能识别与自动优选。

**下载与离线**

- 下载引擎稳定性重写：同进程删除→重新下载不再卡死（代次错位热循环修复），引擎零自旋、可终止。
- 音乐下载三态菜单：下载 / 取消下载 / 删除下载分态呈现，杜绝「下载」误删已下载文件；删除三清（文件 / 索引 / sidecar）。
- 下载索引对账：下载页新增「下载索引对账」入口，dry-run 报告孤儿 / 残片文件，显式确认后清理。
- 断网降级：飞行模式下首页 / 媒体库渲染本地缓存而非整页报错；已下载音乐断网冷启动可见、可播（本地短路，不走网络）。
- 写补偿：断网时收藏（影视 / 季 / 剧 / 音乐）本地排队并提示「已保存，联网后自动同步」，恢复网络后数秒内自动补传，且不覆盖服务端播放状态。

**音乐**

- 通知栏媒体面板、播放队列持久化与断网恢复重解析；歌词逐字 / LRC 双语对照、字号行距可调。
- 修复旧流地址恢复导致的断网卡死（恢复快照按当前链重解析）。

**阅读**

- EPUB / PDF / CBZ 三格式；整本下载完成发通知，点击直达阅读器（不可达时回退下载页已完成分组）。

**搜索**

- 全局搜索覆盖影视 / 音乐 / 书籍并分区展示；修复结果区空白不渲染（根因：布局约束压垮搜索栏结果区）。

**设置与账户**

- 删除当前使用中的服务器地址给出明确 snackbar 提示；切换账户被打断 / 身份恢复中行内红字反馈，不再静默。
- 季页「季 · N」计数在删除剧集后即时刷新；批量操作条在 360dp 窄屏横向滚动，按钮不再被挤压。
