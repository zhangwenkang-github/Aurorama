## 3. 2.0 定义与不可破坏结果

Aurorama 2.0 是正式 `2.0.0` 产品大版本，同时代表内部 V2 架构和研发流程代际升级。它不只是一个版本号、UI 改版或功能集合。

不可破坏结果：

- 从现有正式版升级时，不得丢失或破坏登录、已有下载、书签、阅读进度、歌单、播放进度、偏好设置和本地媒体库。
- 所有服务器写操作只针对用户指定的独立测试写入服务器；生产服务器继续只读。
- 原始需求中的条目默认进入候选范围，未经用户明确批准不得静默删除。
- 每条需求最终必须归类为 `MUST / SHOULD / LATER / OUT`；分类改变必须留痕。
- 2.0 文档的全部需求未完成归一前，不进入产品实现；需求门完成后仍需通过方案门和开发门。

## 10. 分支、QA 与完成定义

- 任务分支：`codex/v2-<任务ID>-<简述>`。
