## 3. 2.0 定义与不可破坏结果

Aurorama 2.0 是正式 `2.0.0` 产品大版本，同时代表内部 V2 架构和研发流程代际升级。它不只是一个版本号、UI 改版或功能集合。

不可破坏结果：

- 从现有正式版升级时，不得丢失或破坏登录、已有下载、书签、阅读进度、歌单、播放进度、偏好设置和本地媒体库。
- 所有服务器写操作只针对用户指定的独立测试写入服务器；生产服务器继续只读。
- 原始需求中的条目默认进入候选范围，未经用户明确批准不得静默删除。
- 每条需求最终必须归类为 `MUST / SHOULD / LATER / OUT`；分类改变必须留痕。
- 2.0 文档的全部需求未完成归一前，不进入产品实现；需求门完成后仍需通过方案门和开发门。

#### 5.3.13 App Logo 原创方向探索

**状态**：`LOGO_EXPLORATION_NOT_ADOPTED`（2026-11-02）。本节保留参考研究、三套原创矢量方向、
确定性 Proof 和独立视觉 QA 作为历史探索；用户随后决定 App Logo / launcher 仍使用当前生产
W38「极光帘幕」自适应图标，A/B/C 不采用，不进入 launcher / splash 派生。

**参考研究**：访问日期均为 `2026-11-02`，完整来源、许可和不可复制边界见
`docs/design/v2-logo-redesign/reference-board.html`。研究覆盖：

- 真实极光与空间视角：NASA Auroras、NASA Magnetospheres、ISS 极光照片。
- 科学结构：NOAA 地球磁层示意、棱镜色散图与真实火石玻璃棱镜照片。
- 观测与束光：ESO 帕瑞纳天文台激光束照片。
- 材质：135 胶片条与拉丝金属照片。

参考图只用于理解物理关系、材质边缘与许可边界，没有下载、拼接、描摹或嵌入仓库。
NASA / NOAA / ESO 标识、署名照片、CC BY / CC BY-SA 构图均不得进入 Logo 或衍生资产。

**研究结论**：

- 极光帘幕需要“大负空间 + 一个主折点 + 清晰亮边”；24px 不保留细褶和粒子。
- 磁层的有效关系是昼侧压缩、夜侧长尾与非对称包围；不应继续使用中心对称菱形。
- 棱镜的品牌价值在硬切面造成方向偏折，不在通用三角或常见光谱科普图。
- 玻璃、胶片与金属只能转译为一道高光、缺口或宽度层级；不使用照片纹理或噪点。

**三个原创方向**：

| ID | 概念 | 一句定位 | 品牌识别核心 | 仅作动效状态 |
|---|---|---|---|---|
| A | 极向光瞳 / Polar Aperture | 被玻璃切面偏折的极光椭圆环，像进入私人影院、音乐与书库的观测入口。 | 开口环 + 4 点钟六边玻璃切面与横向凹槽。 | 内缘光带单向掠过；切点短促提亮。 |
| B | 折光山脊 / Refraction Ridge | 非对称极光帘幕被斜向玻璃横脊折成 A 形山脊，强调电影和材料感。 | 竖向双帘幕 + 越界斜横脊 + 右帘断口。 | 折射点沿横脊移动；帘幕短相位反转。 |
| C | 磁尾航迹 / Magnetotail Trace | 从六边棱镜头部向右上展开的双层磁尾，表达太阳风被观测、折射并留存。 | 六边晶体头部 + 粗 / 细非对称长尾 + 固定方向。 | 双尾短相位收束；头部单次闪亮。 |

  primary / secondary / tertiary，切换后必须重新复核对比度。

##### 5.3.16.5 图标-only、短标签、可访问名称与安全确认边界

| 表达级别 | 允许的动作 | 强制规则 | 禁止 |
|---|---|---|---|
| 纯图标 | 返回、关闭、搜索、菜单 / 更多、播放 / 暂停、上一 / 下一、静音 / 音量、全屏、已约定俗成的传输键 | 24dp 图标置于至少 48×48dp 热区；必须有可访问名称、角色和状态；高对比主题仍可辨 | 删除、取消下载、删除账号 / 服务器、权限、错误、低频率管理动作 |
| 图标 + 短标签 | 下载、收藏 / 已收藏、标记已看、随机 / 顺序、循环、睡眠定时、字幕、音轨、倍速、画面比例、PiP、筛选、排序、视图切换 | 标签使用最短稳定动词；图标只是加速识别；面板内与无障碍名称一致 | 用“更多”“设置”等泛词掩盖具体结果 |
| 可见文本必须保留 | 媒体标题、进度 / 数值、空态说明、错误原因、权限解释、下载 / 失败 / 完成状态、服务器 / 用户身份、管理员入口 | 文案说明发生了什么、对象与下一步；安全信息不能为减少文字静默删除 | 将低频、抽象、危险动作缩成无标签图形 |
| 确认对话 | 删除本地下载 / 数据、清空缓存、移除账号 / 服务器、登出、批删除、移除歌单内容、任何不可逆或大范围动作 | 标题、对象名 / 数量、范围、可恢复性和确认 / 取消；危险键不用无文字图标 | 用纯图标直接执行；把取消键做成唯一无标签选项 |

**可访问性合同**：

- 可操作图标禁止 `contentDescription = null`；相邻已有可见文本的装饰图标才设为 null。
- 切换类动作必须暴露 checked / selected / expanded / busy 等状态，不用颜色或动画作为唯一状态。
- 加载中的动作保留原名称并追加 busy 状态，禁用防重复提交；不能只把图标换成 spinner 后丢失语义。
- 低对比、颜色差异、动效、方向或位置都不能是唯一区分；关键图标至少 4.5:1、目标 7:1，普通图标至少 3:1。
- 48dp 外扩热区不得与相邻动作重叠；批量条、迷你播放器和系统栏同时出现时仍保留可点击边界。
- 错误、权限和危险动作必须语音可读；不得只用震动、红色或极光闪烁传达。
- 视觉稿与实现状态板必须列出每个 icon-only 动作的名称、角色、状态和短标签策略。

**安全确认边界**：可逆、单对象、常见动作立即执行但给结果反馈，如切换 tab、搜索、收藏、暂停 / 继续、
开始单项下载；仅当动作会删除数据、改变账号 / 服务器身份、覆盖 / 清空或影响多项资源时确认。
“取消下载但保留部分文件”“删除本机文件”“从服务器移除”必须明确不同后果，不能共用含糊确认文案。

##### 5.3.16.6 五主题对结构、密度、图标和动效的约束

**跨主题不变量**：信息架构、入口顺序、页面职责、内容顺序、状态语义、可访问名称、最小触控、
加载 / 空 / 错误文案含义和 48dp 底线不随主题变化。主题只能改变色、材质、字阶表现、受控形状、
图标绘制完成度、动效强度与表面层次。主题不得让同一动作换义、隐藏危险提示或改变首页主焦点。

| 主题 | 结构 / 密度表现 | 图标语义与形态 | 动效 | 禁止 |
|---|---|---|---|---|
| Prism | 细线、几何、明确分区；内容页偏影院，管理页偏紧凑；共享 4/8 网格 | 1.75–2dp 几何描边为主，激活态可填充；图标的“动作”不变 | 高响应、克制的状态过渡；150–300ms | 把细线做成低对比、用多色装饰表现层级 |
| Lumen | 默认新装；媒介图更突出、材质更通透，但不得降低信息密度背后的可读性 | 可略增亮度与局部光感；仅少数关键动作允许受控极光状态 | 可更柔和，但仍在 150–300ms；减少动画直接切换 | 全屏光晕、粒子背景、用模糊遮挡标题 / 错误 |
| Nocturne | 高对比、沉浸深色与编辑式排版；“管理”仍比内容浏览更紧凑 | 暖 / 冷双色仅作角色差，不以颜色替代形状；状态有轮廓或填充差 | 克制、可预测，不为氛围加装饰循环 | 中文合成斜体、低对比金色小字、主题专属图标含义 |
| Monolith | 不透明材质、强描边、硬几何；基础 8dp 圆角；管理页更表格化但不突破 48dp | 2dp 左右的强轮廓，激活态填充；不使用材质辉光 | 最短的状态反馈；可减少过渡但保留反馈 | 粗框挤压内容、所有控件同一重量、隐藏层次 |
| 系统动态色 | 沿用 Prism 骨架、几何、字阶与动效；Primary / Secondary / Tertiary 映射视频 / 音乐 / 书籍 | 图标形状不跟壁纸改变；只替换语义色并重算对比 | 跟 Prism 一致，避免壁纸色导致动画闪烁 | 动态色叠加品牌主题、保留硬编码品牌色、Android 12 以下显示可点入口 |

**主题切换合同**：五主题与明暗切换即时全局生效；200ms 可关闭过渡；切换不重载页面、不清空数据、
不重置滚动 / 焦点 / 选择；系统动态色变化后所有状态、图标和插图重新过对比度；主题预览使用内置原创
样例、当前外观与就地明暗切换，不读取真实账号内容。阅读显示主题只覆盖正文显示区域，外框、顶栏、
按钮和弹层仍服从 App 主题。

#### 5.4.4 术语、状态与不变量

1. **书籍来源（origin）**与**读取方式（transport）**正交。来源是 Jellyfin 书目或 SAF 本地书；
   传输是本地文件、远端 Range 或整本下载。不能再用“在线 / 离线”一个布尔值同时表达两者。
2. **离线可用（offline-ready）**是独立事实：只有完整本地副本或本地 SAF 源成立；远端流式阅读中
   不等于离线可读。手动下载中两者可以同时存在。
3. **阅读位置（ReadingPosition）**以稳定 locator 为真源。EPUB 使用 Readium Locator / CFI
   等价锚点；TXT 使用文本偏移并附上下文校验；PDF / CBZ 使用逻辑页索引与页内归一化几何。
   页码、百分比和“第 X / Y 页”都是派生展示值，不能用于跨布局恢复。
4. **进度所有者**：Jellyfin 书目以本地持久记录为即时真源，向 Jellyfin UserData 同步；
   SAF 本地书只在设备本地保存。任何界面显示同一本书的进度时，必须读取同一个位置记录，
   不允许书架、首页和阅读页各自推算。
5. **批注（Annotation）**按重排锚点与固定页锚点分型，但共享 id、bookId、文本摘要、笔记、
   颜色名、createdAt、updatedAt 和格式版本。重排批注禁止保存像素矩形；固定页格式可使用
   页内归一化矩形，因为它不随窗口尺寸变化。
6. **ReaderSettings**是设备级全局阅读偏好，不绑定 Jellyfin 用户或单本书。App 主题、明暗外观、
   阅读显示主题、内容域色仍按 `V2-D021`～`V2-D081` 正交；阅读主题只覆盖正文区。
7. **打开 / 失败状态**至少要能表达：解析来源、连接远端、读取本地、解析文档、首屏布局、
   TTS 能力探测。网络失败、格式不支持、文件损坏、加密 / 权限不足、无文本层和 TTS 无可用引擎
   必须给不同原因与可执行下一步，不能都落到“打不开这本书”。
8. **输入仲裁唯一性**：选区与控件命中优先于双指缩放，双指优先于拖动，拖动优先于单击分区。
   选词 / 框选期间暂停翻页、亮度与控制层手势；双击书签只在开关开启时接管正文双击，并仅在此
   情况下延迟中央单击。任何格式都不得另建一套冲突的手势优先级。
9. **TTS 状态**：引擎能力、播放状态、当前句子、语速与控制条展开状态分别存在。控制条收起不
   等于停止；点击正文或“回到原文”默认暂停，但设备设置可改为继续。运行时只允许已安装的离线
   能力，零远程 API、零自动语音包下载。
10. **取消与重建**：离开阅读页必须取消在途网络、搜索与 TTS；已提交本地文件允许后台继续；
    进程重建后从稳定 locator 恢复，不依赖页面内存或临时页码。

#### 5.4.6 最终 MVP 边界

最终 MVP 边界已由 `V2-D098` 确认。主要取舍：

- 2.0 核心读、写、恢复闭环优先于页动画、自动翻页、导出、在线词典与广泛格式。
- UTF-8 / 常见中文编码 TXT 与 EPUB 同属重排阅读；PDF / CBZ 必须保留各自固定页语义。
- 本地媒体库 / SAF 生命周期仍由现有媒体库负责，阅读器只消费稳定书籍引用，不新建平行书库。
- 阅读位置、设置、批注与 TTS 状态分别建模；任何页面都不得从页码或内存位置反推真源。

  自动滚动、章节已读状态和导出属于“好不好用”，不压 2.0 MVP 核心闭环。
- 手势只保留 `V2-D095` 一张仲裁表；选区、双指、拖动和单击不得由不同格式各自重定义。
- TTS 只接受运行时完全离线；引擎仍待 G1 调研，不在需求基线选型。

**最终 MVP**：包含全部 63 个单级 `MUST`，以及 `READER-046` 的
书签管理与 `READER-057` 的 PDF 搜索两个 `MUST` 子项；不把纯 `SHOULD`、`LATER` 或 `OUT`
静默升入 MVP。

1. EPUB + TXT + PDF + CBZ 的明确重排 / 固定页能力矩阵；
2. 服务器书目、SAF 本地书与完整离线副本三种真实来源及正交状态；
3. 沉浸控制层、分页 / 滚动、统一点击 / 双指 / 拖动 / 选区仲裁；
4. 字体、字号、字距 / 行距等格式适用排版、五套阅读主题、亮度与 locator 保持；
5. 四格式真实目录、全书进度、显式书签管理、自动保存与重启恢复；
6. EPUB/TXT 文本批注、PDF 固定页矩形批注、格式能力显式降级；
