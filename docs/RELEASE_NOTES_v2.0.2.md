# 极光幕 · Aurorama 2.0.2 发布说明

> 2.0.2：UI 重构 / 热修波次（W0–C9），按 `docs/V202_TASKS.md` 台账逐卡核销。版本 2.0.2 / versionCode 9。

## 修复

- **更新下载死锁（U1 热修）**：修复已下载更新包记录丢失 / 不匹配时更新流程卡死的问题——
  检测到已发现版本与本地记录一致时自动重建下载任务并续走校验流程。

## 界面与设计系统

- **安全区统一（D1）**：顶栏 / 搜索页 / 冷启动页 / 阅读器控制层统一按安全绘制区避让状态栏与
  摄像头挖孔；横屏左右挖孔与侧轨同步避让。
- **音乐头部重排（D2）**：收敛为两行——顶栏（搜索 + ⋮）与轻量标签行（40dp 无容器文本标签，
  选中带极光渐变指示条，可横滑）；「播放全部 / 随机」降为 36dp 紧凑行（仅歌曲 / 专辑）。
- **书籍 / 库头部统一（D2）**：同样收敛为两行（标签行 + 行尾计数与排序 / 视图 / 筛选图标键），
  生效筛选 chips 单独一行横滑。
- **最近阅读入流（D3）**：书籍页「最近阅读 / 本地书籍」从页面固定头部改为网格首项，随滚动离开；
  空列表零占位。
- **黑底清理（D4）**：图上控件（徽标 / 返回键 / 多选圆点 / 播放器背板 / 桌面歌词）垫层统一为
  主题玻璃 / scrim token，不再手写黑底。
- **黄橙清零（D5）**：加载圈 / 进度条 / 排序选中 / 下载组件 / 详情氛围光晕等 60+ 处交互强调
  全部归极光色板；域媒体色仅保留身份位（占位底、域徽标、歌词与 Epub 批注等内容标注）。
- **筛选 Chip 统一**：搜索范围、歌词设置、音效面板残留的 M3 原生 FilterChip 统一为设计系统
  `CinefinFilterChip`（40dp / 极光选中语言）。
- **阅读器进度归极光**：全书进度条 / 书签点 / 拖拽 thumb 改极光选中色（浅色纸底用 auroraInk
  保证可读性）；批注框等书页标注保留域身份色。
- 新增设计 token 一致性守卫单测（D4 黑底 / D6 交互槽 / FilterChip / 阅读器 accent 防回退），
  防止样式回退。
