# 极光幕 · Aurorama 1.1.0 发布说明

> v1.0.0 之后的首次更新（2026-10-06 初版，2026-10-07 修复重建）：以修复用户反馈为主（18 条）+ 少量增强，并追加修复 3 项既有缺陷（首次下载必失败 / 音乐后换内核失效 / 系列页「播放」空白等待）。安装方式、校验方式与已知限制见下。

## 关于本版本

极光幕（Aurorama）1.1.0：面向手机 / 平板的第三方原生 Jellyfin 客户端，基于 [Findroid](https://github.com/jarnedemeulemeester/findroid)（GPL-3.0，基线 `a28ac9e`）改造，以直接播放（Direct Play）为主。

包名 `io.github.zhangwenkang.aurorama`，版本 `1.1.0 (2)`，要求 **Android 9（API 28）及以上**。

## 本版亮点与修复

**播放器**

- **转码流快进快退修复**：Exo 内核下拖动进度条 / ± 快进快退 / 手势 seek 不再回到片头；转码流超出缓冲窗口时自动带目标位置重开会话（起播与续播同样携带位置）
- **播放中偶发退出修复**：网络瞬断不再误判为内核故障；原地重试并在恢复后自动续播，播放页不再退回详情页
- **字幕**：句末准时消失（不再拖到下一句）；简 / 繁自动选择更准（按设置的语言优先级）；手动选定的字幕在切换码率后保持；次字幕语言跨视频记忆；主 / 次双语字幕改为**上下两行**显示，不再互相叠加
- **倍速**：同一剧集队列切下一集保持当前倍速（新开一部片仍按 1× 起播）
- **后台播放默认改为关**（已手动设置过的安装保留你的选择）
- **进度条**：已播放的章节刻度改回白色；章节吸附手感增强（吸附范围按片长自适应、明显的轻震动反馈）
- 转码档字幕下载失败会自动重试一次（加固）
- **系列页「播放」修复**：系列详情页点「播放」的空白等待从 8–32 秒降至实测 2–5 秒；解析失败改为明确中文提示、不再静默空载；加载过程中退出播放页不再误报错误
- **内核切换修复**：先播放音乐后，同一进程内进入视频时「解码面板切换内核 / 硬解失败自动回退」不再失效（此前可能弹出「播放失败」卡片且「改用 mpv 内核」无响应）

**媒体库与浏览**

- **库入口一致性**：侧栏 / 媒体库页 / 库选择器三处的库列表完全一致，每个库都能打开；选择某个具体库会**直达该库内容**，不再停在卡片层
- **不再有黑块**：无封面 / 加载中 / 加载失败统一显示「类型图标 + 媒体色」占位（媒体库大卡、条目卡、书籍卡）
- **整季看完有勾**：一季全部集看完后，季卡 / 季行显示已看态，返回一次内刷新
- **「未知季」修复**：无季号的季（如 ISUCA）显示剧集封面，并列出其单集、可正常播放
- **返回保持滚动位置**：列表 / 网格页滚到中段，进条目返回后不再回到顶部
- **管理员入口**：管理员账号登录后第一次打开侧栏即包含「控制台 / 资料管理」
- **全页搜索入口**：视频页 / 音乐 / 书架 / 库内容页顶栏新增搜索入口（复用既有搜索流程）
- **详情页评分**：电影 / 剧集详情信息行显示 `★ x.x`（无评分不显示）

**设置**

- 播放 / 阅读相关设置项全面核对「切换 + 重启保持」：视频「循环 / 随机」改为持久化；长按倍速档、seek 步进改为即时生效；首选语言下拉读数修正

**下载**

- **首次下载修复**：新安装或清除数据后，第一次下载不再必然失败（此前显示「失败 / 0 B」）——下载前会先建立存储目录再检查可用空间

**其它**

- 调试日志脱敏：转码流地址中的鉴权参数不再以明文写入日志（面向开发者 / 问题排查）

## 安装与升级

从 [GitHub Releases](https://github.com/zhangwenkang-github/Aurorama/releases) 下载签名 APK，直接安装（首次安装需允许「安装未知应用」）。**1.0.0 可直接覆盖升级到 1.1.0**（同签名，设置与数据保留）。

| 下载文件 | 面向 | 建议 |
|----------|------|------|
| `Aurorama-1.1.0-universal.apk`（163.2 MB） | 全部 ABI（armeabi-v7a / arm64-v8a / x86 / x86_64） | 不确定机型 / 兼容性优先 |
| `Aurorama-1.1.0-arm64-v8a.apk`（74.0 MB） | 仅 arm64-v8a | 2017 年后的主流 64 位手机 / 平板（体积约为整包一半） |

> 两个包内容一致、同为 release 签名；**同一设备上请始终用同一签名的包升级**（换签名无法覆盖安装）。调试包（`.debug` 后缀）可与正式包共存、数据互相独立。

## 已知限制

- **MIUI（小米 / Redmi）**：系统媒体面板不显示本应用自定义的「关闭」键（系统面板行为限制），可用面板内其它控制键或回到应用内关闭；
- 直接播放优先：服务器端不支持直放的片源会静默转为 HLS（画质 / 音轨以服务器转码设置为准）；硬解与服务器转码都不成功时自动降级 libmpv 软解，功耗与发热更高；
- 本地媒体库受 Android 存储限制：无法选择 `Android/data`、`Android/obb`、其它应用私有目录；
- TV（遥控器 / D-pad）界面未适配，1.1 面向手机与平板；
- 仅做 GitHub Releases 分发，暂无国内商店 / Google Play 渠道。
