# 字幕双内核不重叠约束

**Status**: accepted (2026-10-18)

主字幕与次字幕由 Exo 的 libass + Compose 自绘路径和 mpv 的 `secondary-sid` 路径分别渲染，W74 只修复了前者的底部叠行。产品要求任何时刻不得重叠，因此统一采用“主上 / 次下”的单一布局契约：先测量两块实际高度，在视频安全区内排布；空间不足时次字幕最低缩到自身字号的 80%，仍放不下才隐藏，主字幕不裁切。该约束覆盖 Exo 与 mpv、文本与 ASS/SSA（含固定坐标），并覆盖新 cue 的首帧，不能依赖“下一帧修正”。

**Why**: 不统一双内核会出现一边修复、一边回归；仅按行数或默认位置排版无法处理多行字幕、大字号和 ASS 原生定位。允许瞬时重叠会直接违反用户验收口径。

**Consequences**:

- 需要把测高、安全区与降级策略做成共享规则，而不是两个渲染器各自打补丁。
- 极端空间下次字幕会被隐藏；字幕面板必须说明该行为。
- 主 / 次轨道选择、延迟、颜色、描边、背景和单字幕行为保持不变。

**Alternatives considered**:

- 只修 Exo（rejected）：mpv 仍会违反同一产品约束。
- 永远保留次字幕并持续缩小主字幕（rejected）：主字幕可读性和优先级不可接受。
- 允许首帧重叠、下一帧修正（rejected）：用户明确要求任何时候都不能叠在一起。
