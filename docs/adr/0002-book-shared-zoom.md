# PDF/CBZ 全本共享缩放

**Status**: accepted (2026-10-18)

PDF/CBZ 的缩放从当前 `ZoomableSlot` 的逐页状态提升为文档会话级倍率：分页、双栏、滚动三种模式共享 1×–4× 的倍率，`−/+` 按 25% 步进并以当前视口中心为锚点，双指继续提供连续缩放；翻页后新页重新居中，但倍率不重置。阅读页顶栏只保留返回、书名与设置，缩放 `−/+` 作为独立右下角悬浮条；PDF/CBZ 使用该页面缩放，EPUB 继续使用 Readium 的文本排版缩放。

倍率在同一 App 进程内按书保留，退出阅读页后重开同一本书仍生效；切换书籍或重启 App 回到 1×，不写入偏好。该边界对应用户的“全本共享、不跨书籍、不跨重启”口径，也避免把页面缩放与 EPUB 文本重排混为同一模型。

**Why**: Edge PDF 式阅读需要整页、全本一致的倍率；逐页状态无法满足翻页后保持一致。把倍率放在文档会话层，能让按钮、双指、三种模式和同书重进共享同一事实；不持久化则避免污染其它书和冷启动默认值。

**Consequences**:

- 缩放状态需要从页槽提升为书级会话状态，页槽只保留自己的平移。
- 滚动模式需要同时支持纵向列表滚动与页内横向平移，必须明确手势仲裁。
- 阅读顶栏缩为单入口，搜索、批注、书签、下载、模式和显示设置进入分组的“阅读设置”面板；PDF/CBZ 的缩放悬浮条约 3 秒自动淡出。
- EPUB 的页面缩放与 PDF/CBZ 不共用，避免两套渲染模型互相干扰。

**Alternatives considered**:

- 保持逐页缩放（rejected）：无法满足全本共享。
- 把倍率写入全局偏好并跨书 / 重启记忆（rejected）：用户明确排除，且会让不同书共享错误倍率。
- 让 EPUB 也使用同一页面倍率（rejected）：EPUB 由 Readium 文本排版，页面倍率会破坏重排与分页语义。
- 不提供快速 `−/+`、只保留双指（rejected）：用户明确要求 Edge 式一键缩放。
