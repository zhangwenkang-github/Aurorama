# Cinefin 开发计划

## 目标

基于 Findroid 改造一个以**平板优先**的 Jellyfin 客户端，深色影院风格，功能尽量对齐官方客户端，
并新增官方客户端没有的手势操作与字幕语言智能识别/记忆能力。

## 基座与许可证

* 基座：Findroid（GPL-3.0），上游提交 `a28ac9e`
* 参考（仅参考功能与协议，不复制代码）：jellyfin/jellyfin-android（GPL-2.0，与 GPL-3.0 可能不兼容）
* 本项目对外分发时必须以 GPL-3.0 开源

## 模块划分

| 模块 | 职责 | 状态 |
| --- | --- | --- |
| `:app:phone` | 手机/平板入口、导航、自适应布局 | 已有 |
| `:app:tv` | 电视入口 | 已有雏形，后置 |
| `:core` | 设计系统、通用工具、常量 | 已有，待重构视觉 |
| `:data` | Jellyfin API、Room、仓库、认证、下载 | 已有 |
| `:player:core` | 播放抽象层、队列、轨道模型、进度上报 | 已有 |
| `:player:local` | Media3/ExoPlayer + FFmpeg + libmpv 双内核、字幕渲染 | 已有，待增强 |
| `:player:cast` | 投屏（可选） | 待新增 |
| `:settings` / `:setup` | 设置 / 首连、服务器发现、Quick Connect | 已有 |
| `:modes:film` | 影视模式 | 已有 |

## 关键约束

* 生产服务器**只读**，禁止任何写/删除调用。
* minSdk 26，平板体验优先，其次手机，TV 最后。
* 解码三级策略：硬解 → Media3+FFmpeg 软解 → libmpv 兜底，失败自动降级并提示。
