# 极光幕 · Aurorama 2.0.3 发布说明

> 2.0.3：体验修复波次——用户实测反馈的 11 项问题逐项修复，另经一轮"找茬"复审修掉 5 个 P1。
> 版本 2.0.3 / versionCode 10。

## 播放（核心）

- **切换播放内核后无法播放（P0 级修复）**：修复播放出错切换内核（ExoPlayer / FFmpeg / libmpv）
  后条目再也无法播放、甚至整机任何条目都播不了的死锁——内核切换失败不再销毁重建播放页，
  改为原地恢复；持久化内核偏好落在本机不可用的内核上时自动回落 ExoPlayer 并复位偏好
  （带用户可见提示）；单集解析失败自动按单片起播，不再报"该条目不是可播放的剧集"。
- **播放返回列表回顶**：从播放器返回首页 / 列表不再整页闪 loading、不再回到顶部；
  继续观看进度、已看标记、收藏与改名即时刷新。
- **播放顺序入口**：顺序 / 随机 / 循环控制移到播放页底部控制栏。
- **字幕面板**：轨道列表重排为分行卡片（名称 / 格式来源 / 主·次操作 / 说明），
  文字与图标不再互挤。
- **控件垫层**：打开设置 / 字幕等抽屉时播放控件整体收起，透明垫层只保留一层，
  不再多层叠透；暂停画面降亮不再受面板开关影响。

## 界面

- **删除 / 编辑元数据入口归位**：与官方客户端一致——海报右下角 ⋮ 菜单与详情页 ⋮ 均可触达
  （电影 / 剧集 / 季 / 合集 / 收藏 / 库全链路）。
- **详情页按钮条**：去掉文字标签，纯图标 24dp + 细圆环描边；键宽随屏宽自适应，不再折行；
  宽屏 / 平板动作排带玻璃底盘、播放键保持极光主按钮层级。
- **全局 ⋮ 菜单图标**：统一为 24dp 矢量图标（原 17sp 文本字形偏小），触控面 ≥44dp。
- **首页**：视频卡片不再显示评分。
- **音乐页**：两个 ⋮ 菜单合并为顶栏单一入口，功能一项不少；菜单文案补齐多语言。

## 更新

- **"下载更新"无反应（根因修复）**：本地下载状态记录损坏会导致下载永久失败且点击无任何
  反馈——现在自动自愈清理，点击立即显示"正在开始下载"；排队等待网络时明示且可随时取消；
  下载进行中禁用重复检查；重试不再闪旧错误。

## 其他

- 新增 / 更新单元测试 60+ 条（内核自愈、首页合并刷新、更新调度、详情动作条布局、
  菜单可见性等），设计 token 守卫同步扩展。
