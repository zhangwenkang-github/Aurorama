# 极光幕 · Aurorama 2.0.1 发布说明

> 2.0.1：修复与打磨波次（W0–W5），按 `docs/V201_TASKS.md` 台账 24 卡逐卡核销。版本 2.0.1 / versionCode 8。

## 行为变化

- **音乐默认 Tab（W5-T24）**：音乐页冷启动从「专辑」改为落在「建议」Tab（Tab 序列建议居首）；
  手动切换只作用于当前页面，不持久化。
- **音乐队列语义（W3-T17）**：点击单曲从「按当前列表整列重建队列」改为「把该曲追加到播放队列队尾并立即起播」；
  已在队列中的曲目不会重复追加，直接跳到既有位置。只有「播放全部 / 随机播放」仍整列加载队列
  （专辑 / 艺术家 / 歌单等详情层点歌会从该曲起按列表顺序补到队尾，保持连续播放）。
- **抽屉手势（W2-T11）**：抽屉不再整屏右滑唤出，改为左缘窄热区右滑唤出（与系统返回手势共存），
  页面中部横向滑动不再误开抽屉；打开后仍可全屏拖回关闭。
- **滑杆手势（W2-T12）**：进度 / 字号等滑杆只在明确横向拖动时才接管，斜向滑动放行页面滚动；
  按下不再即时落位，水平拖动落位、点按抬手落位。
- **播放设置入口（W2-T13 / W4-T23）**：播放设置面板从 12 项精简到 6 项；「串流码率」从播放器底栏
  迁移到 设置 → 播放器 子页，播放器底栏 6 键减为 5 键。
- **音乐播放页（W3-T18）**：全屏播放页功能收敛为单入口——底部「音效 / 歌词 / 队列」三键，
  其余收进顶部菜单；打开全屏播放页时隐藏 App 底栏，返回即恢复。

## 新增

- **音乐工具行（W3-T14）**：Tab 序列 = 建议 / 歌曲 / 专辑 / 艺术家 / 歌单；「建议」含最近添加 /
  最常播放 / 收藏三段；⋮ 收纳来源筛选、徽标开关、6 键排序（升降序持久化）、收藏筛选、每页数量；
  歌曲 Tab 客户端分页 + 底部页码栏。
- **歌曲行菜单（W3-T15）**：⋮ 与长按统一为完整上下文菜单（播放 / 下一首播放 / 加入队列 / 加入歌单 /
  收藏 / 下载 / 查看专辑 / 查看艺术家 / 刷新元数据 / 音频信息）；宽屏档位右侧提升为三个独立图标。
- **服务器歌单写操作（W3-T19）**：服务器歌单支持重命名、删除（有确认提示）、歌单内上移 / 下移 / 移出曲目。
- **元数据刷新（W3-T20）**：歌曲 ⋮「刷新元数据」真实调用服务器刷新并回读合并；无封面曲目自动只读补取
  （节流，永不自动写服务器）。
- **更新说明（W1-T01）**：更新页展示 GitHub Release 的发布说明正文。

## 修复

- **更新链路（W1-T01）**：手动检查更新重复触发不再互相取消；下载包校验缺失摘要时不再误删安装包；
  修复部分机型无法拉起 APK 安装界面的问题。
- **管理员入口（W1-T02/T02b）**：修复查询失败时管理员入口被错误隐藏的问题。
- **剧集页静默刷新（W1-T05）**：播放返回后季 / 集列表不再整块闪空重排。
- **多选错位（W1-T06）**：修复季页进入多选时内容下移错位。
- **跨季误下载（W1-T07）**：修复整季下载把其他季同号集误并入的问题。
- **搜索音乐结果（W1-T08）**：修复搜索结果里音乐条目无法进入对应详情页的问题（专辑 / 艺术家 / 歌单
  进详情层，歌曲起播并打开所属专辑）；底栏高亮与返回链路同步修复。
- **竖屏播放器（W4-T21/T22）**：竖屏顶栏整体下移避开状态栏 / 摄像头挖孔；修复竖屏锁定后无法解锁；
  锁定 / 解锁键尺寸统一；横竖屏跟随口径改为跟随系统设置。
- **主题还原（W2-T09/T10）**：琥珀色退出交互强调位，交互强调统一为极光渐变（按钮 / 进度 / 选中 /
  开关 / 滑杆）；评分徽标改极光淡色；图标去方框磁贴底、着色规范统一。
- **主题选择器**：新增「跟随系统」。

## 其他

- 新 Logo「极幕之眼」（W1-T03）；图片缓存默认改为无限制（W1-T04）；音乐多选统一为长按进入（W3-T16）。

## 已知限制

- 「建议」Tab 的「最常播放」按最近播放顺序近似（无播放计数表）。
- 元数据刷新回读为固定延迟，慢元数据提供器可能需再次手动刷新。
