## 1. 项目定位

Cinefin 是基于 **Findroid**（GPL-3.0，上游 `a28ac9e`）改造的自用 **Jellyfin Android 客户端**：

- 现有能力：电影 / 剧集浏览与播放（ExoPlayer 硬解 + FFmpeg 软解 + libmpv 二级兜底）、手势体系、
  字幕 / 音轨语言智能识别与跨片记忆、离线下载、Web 控制台皮肤。
- 本期目标：在保持播放器稳定的前提下，新增**电子书阅读**、**音乐播放**、**UI 差异化重设计**，
  并以 **jellyfin-web 功能集**为基线逐步实现官方客户端功能对等（parity）。
- 许可证：GPL-3.0。新增第三方库必须通过许可审查（AGPL、GPL-2.0-only 代码不可并入）。

### 1.1 官方客户端基线（调查结论）

- Jellyfin 官方 Android 客户端（v2.7.3）本质是 **WebView 包装 + 原生播放器**，功能主体即 jellyfin-web。
- jellyfin-web 内置：`epubjs`（EPUB 阅读）、`pdfjs-dist`（PDF 阅读）、漫画图片阅读、歌词编辑 / 上传组件。
- Jellyfin 服务端支持书籍格式：`azw/azw3/cb7/cbr/cbt/cbz/epub/mobi/pdf/zip/rar/7z`；有声书支持常见音频格式；
  **不支持 read-along（有声书与文本逐句联动）**，该项明确排除。
- 服务端已具备本期所需 API：`/UserItems/{itemId}/UserData`（进度）、`/Audio/{itemId}/Lyrics` + 远程搜索（歌词）、
  `/Items/RemoteSearch/Book`（书籍远程搜索）。

| MU-9 | 进度上报：播放进度写回 Jellyfin | 复用 `Sessions/Playing` 系列接口 |

### 5.1 歌词双语识别细则（MU-5）

- 数据形态：**同一份 LRC，原文行 + 翻译行**（可能共享时间戳，或成对相邻）；
  外挂歌词来源多样，需先兼容常见 LRC 变体（时间戳格式、`[offset:]`、多标签）。
- **原文行可能混合多种语言；中文行也可能夹带英文**——因此语言识别必须**逐行进行**，
  不得用整文件语言判定。

**实测结构（2026-09-29，服务器 10.11.8，`GET /Audio/{itemId}/Lyrics`）**：

| 样例 | 结构 |
|------|------|
| aLIEz（83 行） | 日文原文 + 中文翻译**共享同一 `Start` 时间戳**成对出现（如 28440000 两条）；含作词/作曲/编曲元数据行 |
| Brave Shine（27 行） | 同模式（如 166590000 原文 + 翻译） |
| 爱的回归线（57 行） | 纯中文歌词（无翻译对） |

→ 双语配对算法可直接依据"**相同 / 极近 `Start` 时间戳成对**"实现；语言识别逐行进行。
- 客户端能力：
  1. 自动配对"原文 / 翻译"行；
  2. 按行语言检测生成可选语言列表（至少：简体中文、繁体中文、英文、日文、原文）；
  3. 用户可切换显示语言；**默认简体中文**（存在中文翻译时优先展示，否则回落原文）；
  4. 支持"双语对照"显示模式（原文 + 翻译同时展示）。
- 验收样例（用户提供）：`aLIEz`、`Brave Shine`、`爱的回归线`。
- 逐字卡拉 OK、在线翻译后置。

## 6. UI 差异化重设计需求（UI）

| 编号 | 需求 | 说明 |
|------|------|------|
| UI-1 | **推翻现有"墨 + 朱砂"基调，全新设计** | 用户明确现状"太单调"；参考 Apple TV 设计语言（沉浸大图、焦点式内容、克制层次、优雅动效），但不得照抄 |
| UI-2 | 设计流程：先出方向稿，后出全套 | 2–3 个方向 × 关键页视觉稿（图片文件）→ 用户选定 → 完整设计系统 + 全套页面稿 |

| UI-4 | 品牌：App 名称可改（随设计方向提案） | 新图标须与现有元素差异明显、体现多媒体元素；启动图、模块图标一并重做 |
| UI-5 | 深浅色 | 主 App 深色为主、保留浅色；阅读器完整主题（纸色 / 护眼 / 深色 / OLED） |
| UI-6 | 多形态 | 手机 + 平板（含折叠展开态）必须；TV 保持冻结（保证可编译）；车机不做 |
| UI-7 | 动效 | 克制，以内容过渡为主；不做炫技动画 |
| UI-8 | 视觉稿上下文纪律 | 生成图片以**文件**交付（用户直接看文件）；会话内禁止贴大图，避免占用上下文 |

## 11. 服务端与接口约束

- 服务器：`https://jellyfins.zhangwenkang.com`（Jellyfin 10.11.8）。
- **禁止**：媒体库修改 / 删除、扫描、用户管理、任何破坏性调用。
- **写白名单（已授权）**：用户数据类接口——播放 / 阅读进度（`/UserItems/{itemId}/UserData`）、
  收藏标记、播放上报（`Sessions/Playing*`）、播放列表读写。
- 测试内容现状：
  - 书籍：1 本 EPUB（PDF / CBZ 由用户后续补充）；
  - 音乐：多首，部分带外挂歌词（样例：`aLIEz`、`Brave Shine`、`爱的回归线`）。
- 服务端缺失能力（已确认）：read-along 联动（不做）。
- **开发凭据管理**：本地凭据存于 `Cinefin/.env.local`（已被 `.gitignore` 忽略）；仓库为 **public**，
  任何情况下不得把凭据写入仓库、文档、提交信息或会话输出；凭据轮换时同步更新本地文件。

## 12. 验收标准

### 12.1 通用门禁（每个 PR 必过）

1. 编译通过：`:app:phone:compileLibreDebugKotlin`（必要时 `assembleLibreDebug`）；
2. `ktfmtCheck` 通过；
3. 新增逻辑具备单元测试（解析器、匹配算法、队列、语言识别等）；
4. 项目负责人 + 架构师会话审查通过；
5. 真机验证记录（Pad 5 / K60；截图或日志留档）。

### 12.2 功能验收要点（节选，分阶段细化）

- **电子书**：EPUB 打开与渲染正确；滚动 / 分页 / 双栏切换；排版与主题设置即时生效并持久化；
  进度写回并在退出重进后恢复；离线可读；PDF 分页懒加载流畅（内存峰值不随文档大小线性增长）；CBZ 翻页与 RTL 正确。
- **音乐**：库浏览完整；专辑 / 歌单连播；队列操作正确；gapless 听觉无缝隙；
  歌词双语识别正确、语言切换正确、默认简体中文生效、滚动同步准确；离线下载与离线播放可用；后台 / 锁屏 / 耳机按键正常。
- **UI**：设计系统 token 全量落地（无遗留旧配色）；手机与平板布局无回归；动效流畅、无卡顿。
- **性能红线**：启动时间、内存占用、APK 体积不发生明显劣化（对比基线，超阈值需评审说明）。

### 12.3 阶段验收

- 用户在**阶段里程碑**验收（不要求每个 PR 过目）；
- 每个 PR 由项目负责人 + 架构师会话审查后合并。
