| `V2-Q-UX-08` | 影视 / 音乐 / 书籍域色是否跨主题固定？ | 每个主题拥有自己的三域色组，但“影视 / 音乐 / 书籍”语义角色固定；单屏仍只使用当前域色。 | 待用户回答 |
| `V2-Q-UX-09` | 多主题下字体如何控制？ | 产品 UI 全局最多 2 个字族，优先 MiSans + Literata；主题用字阶、字重和排版比例表达差异，阅读正文用户字体不计入 UI 字族。 | 待用户回答 |
| `V2-Q-UX-10` | 多主题下圆角如何处理？ | 每个主题只选一个基础圆角（8 / 12 / 16dp 中三选一）；圆点、胶囊和圆形作为形状而非额外圆角，组件不得自造字面值。 | 待用户回答 |
| `V2-Q-UX-11` | 主题动效的时长和例外如何统一？ | 主题驱动的界面交互动效统一为 150–300ms；播放进度、歌词等高信息内容运动不属于装饰性主题动效，遵守减少动画。 | 待用户回答 |
| `V2-Q-UX-12` | Android 触屏上的状态矩阵如何落地？ | 默认、按下、聚焦、禁用、加载、空、错误为必测；Hover 仅用于鼠标 / 触控板等指针环境，不伪造触屏 Hover。 | 待用户回答 |
| `V2-Q-UX-13` | “首屏不得卡片堆叠”如何与媒体内容墙共存？ | 首屏必须有单一主视觉焦点和清晰留白；媒体海报墙作为内容浏览允许使用卡片，禁止把统计模块、说明、按钮堆成仪表盘式首屏。 | 待用户回答 |
