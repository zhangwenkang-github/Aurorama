# S1 方向对比与推荐

| 维度 | A · Lumen 流光 | B · Prism 棱镜 | C · Nocturne 夜曲 |
|------|----------------|----------------|-------------------|
| 一句话 | 黑场沉浸，内容即光源 | 结构恒定，三色媒体身份 | 暖色触感，唱片与纸页 |
| 最强项 | 首页 / 播放器最"影院"，记忆点单一而清晰 | 影、乐、书三域一眼可分，平板双栏可扩展性最好 | 音乐与阅读最有专属气质，最不"像播放器" |
| 主要风险 | 容易与其他深色播放器同质 | 需要强色彩纪律，否则回潮成"到处是颜色" | 暖调与冷色海报需统一色温，材质细节成本高 |
| 落地成本 | 低（组件最少、token 最简） | 中（三色 token + 双栏栅格） | 中高（噪点 / 画框 / 字体细节多） |

**推荐：以 B 为骨架，吸收 A 的沉浸手法，把 C 留作音乐与阅读的专属皮肤。**

理由：需求是"三种媒体 + 平板优先 + 长期扩展"，B 的双栏栅格与三色身份一次性解决首页、媒体库、音乐、书架的区分问题，列表化详情页信息密度最高，后续 parity 页面可直接沿用同一套结构；把 A 的全出血头图与焦点动效放进首页与播放器，即可补上"记忆点"；C 的黑胶与纸页语言最适合作为音乐、阅读两个域的第二步细化，避免同时承担全局复杂度。

三套均已交付 5 张必选屏（首页 / 详情 / 播放器 / 音乐正在播放 / 阅读页）+ 阅读器纸色变体 + 1 张额外屏 + 手机竖屏示意 + 图标概念，可直接进入用户评审。
