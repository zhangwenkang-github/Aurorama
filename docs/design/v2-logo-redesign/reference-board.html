Aurorama / Logo research 01

极光不是背景，而是一套可被折射、观测与收束的结构。

研究真实极光摄影、太阳风与磁层、棱镜色散、束光、夜空、玻璃 / 金属 / 胶片与天文台科学可视化。 本板只记录观察、来源和边界；没有下载或拼贴任何第三方图片，三个 Logo 方向均从零以原创 SVG 构造。

四条可吸收、不可复刻的规律

提取结构关系，不提取摄影构图、纹理、轮廓、色带顺序或品牌识别元素。

帘幕：纵向层叠

真实极光以不规则帘幕、清晰下缘和大面积负空间形成层次；小尺寸应保留一个主折点，不保留细褶与粒子。

场形：压缩与长尾

磁层不是正圆：昼侧受太阳风压缩，夜侧形成长尾。适合转译成非对称环、偏心焦点和方向明确的扫线。

棱镜：硬切面 + 分光

白色入射光在硬质斜面处分色。Logo 需要明确的硬 / 软对比，避免把棱镜继续画成通用菱形徽章或三角山符号。

材质：只表达边缘

玻璃看高光与透光，拉丝金属看向导，胶片看孔列与帧缝。小尺寸只保留一道高光或一个缺口，不铺噪声纹理。
