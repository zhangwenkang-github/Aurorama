Aurorama / Logo directions

三条从零出发的路径：光瞳、山脊、磁尾。

三者都保留“棱镜 + 极光帘幕”与品牌入口感，但使用完全不同的几何语法。旧 Logo 的菱形主体、水平入射方向、 三股平行光带和微粒位置均未沿用；新方向也不依赖页面极光、纹理背景或持续粒子。

A / OVAL

Polar Aperture

极向光瞳

接近闭合的极光椭圆环接入带横向凹槽的六边切面玻璃，像从夜空进入私人影院、音乐与书库的入口。

识别核心椭圆环 + 4 点钟方向的六边玻璃片与横向凹槽；不使用箭头尖端。
动效状态内缘光带单向掠过或切点闪亮一次；静态图标保持完整，减少动画时关闭。
气质安静、科学、可信任；从太空观测轨道与天文仪器借形，但不画星球。

B / MONOGRAM

Refraction Ridge

折光山脊

不对称双竖向极光帘幕被斜向玻璃横脊折成 A 形，右帘幕玻璃断口带来明确材料特征。

识别核心非对称双帘幕 + 越过左侧的玻璃横脊 + 右帘幕玻璃断口。
动效状态折射点沿横脊移动或帘幕做一次相位反转；不持续漂动。
气质电影、玻璃、胶片与建筑；比 A 更有棱角，也比旧稿更纵向、更克制。

C / TAIL

Magnetotail Trace

磁尾航迹

不规则六边棱镜头部连接分离的粗细双尾，向右上展开成非对称磁尾航迹。

识别核心六边切面头部 + 宽度差双尾 + 贯穿两尾的连续负空间。
动效状态两层尾部以 24–40ms 相位差缓慢收束一次；不是常驻粒子轨迹。
气质探索、流动、科学可视化；最像运动品牌，也最依赖方向与轮廓清晰度。

A / 极向光瞳
环与切口保持清晰；光带可映射三域色，但不超过两段高彩。
最适合；青色内光 + 深玻璃底，保留默认主题的冷暖平衡。
棱镜切口转暖金，环内光收为低饱和蓝紫；不使用绿色主导。
去掉溢光，只保留实心 / 描边两色；8dp 外壳，几何最稳。
环用 M3 primary，切口用 secondary；必须实时验证对比度，不能写死品牌青。
B / 折光山脊
左帘可保留极光青，横脊用暖金；两主题色最多，需避免过满。
玻璃横脊最符合 Lumen 材质；保留中央冷光缝，不增加背景光。
横脊暖金、帘幕深蓝；更像胶片与暗室，适合 Nocturne。
关闭玻璃透明，横脊变实心钢片；最简洁，但会失去一半材料感。
帘幕取 primary，横脊取 tertiary；不得同时给三角分别映射三域。
C / 磁尾航迹
双层尾线可采用青到蓝；棱镜头部用白色 / 暖金单点，保持方向清楚。
最流畅；尾部双层青色具动势，但静态必须收束，不做持续流光。
尾线转靛蓝，棱镜边缘转琥珀；更像航迹与旧式天文底片。
用三级宽度而非三种颜色区分尾部；强对比下辨识度最高。
外层 primary、内层 secondary；动态色下取消尾部渐变，保留双线宽度差。
