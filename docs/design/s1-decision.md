# S1 设计方向决策记录（2026-09-29）

## 1. 用户决策

**采用 S1 推荐的组合方案**：

| 组成 | 来源 | 作用 |
|------|------|------|
| 骨架 | **B · Prism 棱镜** | 结构恒定 + 三色媒体身份 + 平板双栏栅格 |
| 沉浸手法 | **A · Lumen 流光** | 全出血头图、焦点动效（用于首页与播放器） |
| 专属皮肤 | **C · Nocturne 夜曲** | 音乐与阅读两个域的暖色 / 唱片 / 纸页语言 |

App 名称暂定 **Prism 棱镜**（可继续称 Cinefin Prism）；图标沿用"三棱镜光栅"概念（白入彩出，三色带）。

## 2. 用户修订（必须执行）

1. **媒体色块融入按钮，不得独立显示在按钮旁**
   - 取消"按钮右侧单独一个小色块"的做法；
   - 媒体色应融入按钮本身：按钮底色 / 描边 / 图标 / 文字着色四种变形；
   - 适用所有出现"按钮 + 色块"的位置：详情页行动按钮、媒体库筛选、卡片 CTA、列表行操作等。
2. 其余设计要求不变（三色纪律：同一屏只出现当前内容域的 1 个媒体色；首页与设置页例外）。

## 3. 落地要求（交给设计系统与实现会话）

- 设计系统必须定义**按钮的媒体色变形规则**：填充态 / 描边态 / 文本态 / 图标态、按下与焦点态、禁用态；
- 交互控件（按钮、分段控件、筛选 chip）的选中态统一使用媒体色，禁止另起"色块徽标"；
- 详情页与媒体库需按新规则重绘（在 UI 设计系统完成时同步更新视觉稿）。
