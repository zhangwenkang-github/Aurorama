# 方向 B · Prism 棱镜 —— 秩序画廊

> 设计会话：S1（2026-09-29）｜状态：方向稿（待用户选定）｜App 名称提案：**Prism 棱镜**

## 1. 一句话理念

**一束光穿过棱镜，分成影视、音乐、阅读三条路径。** 结构恒定、色彩流动：版面与栅格始终如一（Linear/Arc 式的精确表面与细线），但每个内容域拥有自己的媒体色。目标是让"三种媒体共存"这件事在视觉上被一眼读懂，同时保持平板双栏下的高信息密度与可读性。

## 2. 色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 石板蓝黑 | `#151A21` | 全局底色（比纯黑更有空气感） |
| 面板 | `#1B212B` | 卡片 / 列表底 |
| 面板·亮 | `#222A36` | 悬浮、选中、分段控件 |
| 结构线 | `#2C3542` | 1px 分隔线与卡片描边（**本方向的骨架**） |
| 奶白 | `#F4F1EA` | 主文字（避免纯白刺眼） |
| 次级文字 | `#A7B0BD` | 说明、元信息 |
| 影视 · 琥珀 | `#E8A15C` | 影视域强调（进度、当前集、主行动） |
| 音乐 · 松石 | `#3FC9A0` | 音乐域强调（播放态、进度） |
| 阅读 · 天青 | `#6FA8FF` | 阅读域强调（进度、章节线） |

色彩纪律：**同一屏内只使用当前内容域的 1 个媒体色**；三色只允许出现在首页（三域并列）与设置页（主题选择）。

## 3. 字体策略

- 中文 UI：**MiSans / Noto Sans SC**（600 标题、400 正文）
- 编辑式标题：**Georgia 斜体**用于英文副题、章节名（如 `Chapter III · 灯塔`）、专辑与书名点缀 —— 制造"档案 / 画廊"气质
- 数据与编号：**Cascadia Mono**（集数、时长、文件信息、队列序号）
- 排版纪律：页面标题 40px / 详情主标题 52px / 区块标题 23px / 正文 17px（行高 1.95）；正文行宽 ≤ 60 个汉字。

## 4. 材质与层次

- **细线优先**：用 1px 结构线组织信息（列表、表格式元信息），取代"处处卡片"；卡片只用 1px 描边 + 顶部内高光，无投影。
- 双层嵌套：外壳 1px 渐变描边 + 内核面板；半径 28 / 22 / 16，同心递减。
- 背景：极淡噪点（4.5%）+ 详情页顶部一张低饱和头图，不加彩色光晕 —— 让结构线成为唯一装饰。
- 网格：平板内容区 = 左侧 164px 标签导航 + 12 列栅格，列间距 26，页面内边距 48。

## 5. 动效基调

- 卡片与列表入场：`opacity 0→1` + `translate-y 8px→0` + `blur 6px→0`，560ms；列表项错峰 40ms。
- 分区切换使用 shared-container（媒体库 → 详情），曲线 `cubic-bezier(0.2, 0.8, 0.2, 1)`；面板（播放器右滑层）420ms 升起。
- 悬停/焦点：描边由 `#2C3542` 过渡到媒体色（200ms），不做位移或缩放。

## 6. 气质关键词

秩序 · 编辑 · 清晰 · 可信 · 三色身份

## 7. App 名称与图标概念

- 名称：**Prism 棱镜**（可继续叫 Cinefin Prism）。
- 图标：**三棱镜光栅** —— 白色光束从左侧射入一枚三角棱镜，右侧分出琥珀 / 松石 / 天青三条色带。无播放三角、无胶片孔、无字母，靠"白入彩出"表达多媒体聚合，在 48px 下仍可读（三角 + 三色带）。

## 9. 形态适配

- 平板：标签导航 + 三栏详情 / 双栏阅读，信息密度高但保持 48px 外边距。
- 手机：底部 4 tab（影 / 乐 / 书 / 更多），列表转卡片；歌词与队列改为上下堆叠。
- 折叠展开态：左导航自动展开为带文字标签，内容区由 8 列扩到 12 列。

## 10. 与需求文档的对应

覆盖 UI-1 至 UI-8；其中 UI-3 的音乐（浏览 / 正在播放 / 队列 / 歌词）由 `music.png` + `bookshelf.png` 之外的列表结构体现，MU-5 的**逐行语言切换**在 `music.png` 与 `phone.png` 中直接可见；EB-6/EB-7（排版与主题）在 `reader*.png` 面板中体现；PARITY 批次 2 的"播放列表管理"在面包屑与队列面板中预留。

## 12. 已知取舍

- 三色体系对"深色一致性"提出更高要求：落地时需把媒体色收敛为 3 个 token 并禁止业务侧自定义色值，否则容易回到"到处都是颜色"的老问题。
- 详情页以列表代替卡片墙，单屏信息密度高于方向 A/C；手机端需要额外的折叠策略（已列为全套阶段任务）。
