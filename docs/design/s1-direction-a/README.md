# 方向 A · Lumen 流光 —— 沉浸银幕

> 设计会话：S1（2026-09-29）｜状态：方向稿（待用户选定）｜App 名称提案：**Cinefin**（保留，副名「流光」）

## 1. 一句话理念

**让内容成为唯一的光源。** 黑场是幕布，画面与海报以全出血方式占据视线；界面只在需要时浮现，焦点处有一圈极光青的柔光。参考 Apple TV 的"内容先行、焦点即放大、克制层次"，但不复制其组件与配色，改用自有的"光晕焦点 + 光路缺口"语言。

## 2. 色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 曜石黑 | `#08090C` | 全局底色（OLED 友好） |
| 石墨 | `#111319` | 卡片 / 面板底色 |
| 雾灰 | `#171A21` | 次级面板、悬浮层 |
| 月白 | `#F2F5F9` | 主文字、主按钮底 |
| 次级文字 | `#98A2B3` | 说明、元信息 |
| 极光青 | `#5CE1D2` | **唯一强调色**：焦点环、进度、激活态 |
| 辅光蓝 | `#7CC4FF` | 仅用于渐变辅助（<10% 用量） |

色彩纪律：一屏内强调色只出现在"当前进度 / 当前焦点 / 主行动"三处；其余全部交给内容图与灰阶。禁止再引入第二种强调色。

## 3. 字体策略

- 中文 UI：**Noto Sans SC**（500/600 用于标题，400 用于正文）
- 拉丁与数字骨架：**Bahnschrift**（DIN 气质，用于时间码、编号、英文标签）
- 技术数据：**Cascadia Mono**（等宽，用于 `01:25 / 1:23:00`、文件信息）
- 排版纪律：海报标题 60–64px / 区块标题 25px / 卡片标题 19px / 元信息 15px；行高 1.05（大标题）与 1.9（正文）。

## 4. 材质与层次

- **双层嵌套（Double-Bezel）**：所有卡片 = 外壳（1px 渐变描边，模拟铝框）+ 内核（纯色面板 + 顶部 1px 内高光）；半径梯度 34 → 26 → 18，保证同心。
- 背景：纯黑 + 极淡胶片颗粒（`feTurbulence`, opacity 5%，混合模式 overlay）+ 首页 hero 背后一层极光晕。
- 图像：全出血 + 底部渐隐遮罩 + 内暗角（`inset 0 0 160px`），避免硬边。
- 阴影：只使用"大范围、低不透明度"的环境投影，禁止 `shadow-md` 式硬投影。

## 5. 动效基调

- 焦点放大 1.04–1.06 + 3px 视差；卡片入场 `translate-y 16px + blur 6px → 0`，600ms。
- 曲线统一 `cubic-bezier(0.32, 0.72, 0, 1)`；播放器控制层淡入 + 上浮 12px，280ms。
- 详情页采用海报 → 头图的共享元素展开；转场期间不做缩放弹跳（克制）。
- 只用 `transform / opacity` 做动画；模糊仅施加于固定层（顶栏、控制层、弹层）。

## 6. 气质关键词

影院 · 沉浸 · 克制 · 光学 · 夜间

## 7. App 名称与图标概念

- 名称：**Cinefin（保留）**，副名「流光」。
- 图标：**光圈棱镜** —— 六段圆弧构成镜头光圈，缺口是一条"光路"，中心一枚极光青亮点即画面本身。与 Findroid 现有的实心播放三角完全不同：无三角、无字母、无渐变填充，靠"环 + 缺口 + 光点"三要素在多尺寸下保持辨识。

## 9. 形态适配

- 平板（主验收 Xiaomi Pad 5，16:10）：所有关键屏均已按 2048×1280 出稿；内容区 12 列、边距 148/46。
- 手机（Redmi K60，20:9）：底部胶囊导航 5 入口，hero 卡片化，货架横向滑动。
- 折叠展开态：左侧悬浮轨可收起为 2 个入口，内容区自动扩列（沿用同一栅格）。
- TV：本方向不涉及，`app/tv` 保持冻结。
