# 方向 C · Nocturne 夜曲 —— 温暖触感

> 设计会话：S1（2026-09-29）｜状态：方向稿（待用户选定）｜App 名称提案：**Nocturne 夜曲**

## 1. 一句话理念

**把 App 做成一间深夜书房：一张唱片封套 + 一本摊开的书。** 深咖底色、纸色文字、黄铜细线、柔光噪点；音乐与阅读是主角，影视为辅。与"影院风"最大的差别在于材质：不是玻璃与黑场，而是纸、木、黄铜与唱片沟槽。

## 2. 色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 深咖 | `#141110` | 全局底色（暖调暗色，非纯黑） |
| 烟褐 | `#1E1916` | 卡片 / 面板 |
| 暖木 | `#262019` | 悬浮层、唱片托 |
| 纸色 | `#EFE6D8` | 主文字（暖白，长时间阅读不刺眼） |
| 次级文字 | `#A99C8A` | 说明与元信息 |
| 黄铜 | `#C8A96B` | 主强调：进度、章节线、选中、播放键 |
| 苔绿 | `#8FA07A` | 第二强调（仅用于"阅读进度"与护眼语义） |
| 阅读纸色 | `#F3E9D6` / 护眼 `#E0DFC4` | 阅读器独立主题（与主 App 解耦） |

色彩纪律：主 App 只用黄铜，苔绿只出现在阅读语境；橙红、紫色、霓虹色一律禁用。

## 3. 字体策略

- 拉丁与标题：**Georgia**（衬线，唱片封套与书脊的气质；用于英文副题、数字、书名）
- 中文 UI：**Noto Sans SC**（600 标题 / 400 正文）
- 阅读正文：**宋体（SimSun → 落地建议思源宋体）**，行高 2.05，两端对齐，首字用黄铜色下沉字
- 数据：**Cascadia Mono**（时间码、页数、码率）
- 排版纪律：页面标题 52px（音乐）/ 56px（详情）/ 正文 25px 阅读（约 30 字/行）；不出现全大写标签堆叠。

## 4. 材质与层次

- **触感三件套**：纸纹噪点（7%，multiply/overlay 双模式）、黄铜 1px 细线（`rgba(200,169,107,.28)`）、圆形唱片沟槽（`repeating-radial-gradient` 1px 环）。
- 卡片：暖色面板 + 1px 暖色描边；详情页海报使用"画框"（外框 + 内衬 + 3px 内边距），像挂画而不是卡片。
- 层次：柔光暗角替代投影；所有圆角偏小（24/16/10），页面边距大（52px），阅读正文列宽 1060px 居中。

## 5. 动效基调

- 唱片：播放时以 20 秒/圈匀速旋转（仅 `transform: rotate`），暂停即缓停到 0.4 秒。
- 面板与层：280–420ms 升起，曲线 `cubic-bezier(0.22, 0.61, 0.36, 1)`。
- 阅读：翻页用 220ms 交叉淡入（不做仿真翻页），章节切换有一次黄铜细线的横向展开。
- 禁止发光脉冲、粒子、光斑循环等"炫技"动画。

## 6. 气质关键词

温暖 · 触感 · 深夜 · 私密 · 收藏感

## 7. App 名称与图标概念

- 名称：**Nocturne 夜曲**（可称 Cinefin Nocturne）。
- 图标：**唱片与纸页** —— 深色圆盘上的同心沟槽代表音乐，右下角一张折角纸页代表阅读，黄铜中心点代表"夜里的那盏灯"。三元素均为实心几何形，无渐变描边，48px 下只剩"圆盘 + 折角 + 铜点"，与 Findroid 元素（播放三角）无重叠。

## 9. 形态适配

- 平板：左导航为 118px 细轨（图标 + 小标签），内容区以"双主角"版式开场；阅读器进入全屏沉浸（无导航）。
- 手机：阅读页独占全屏，工具条收敛为 3 个圆形按钮；音乐页黑胶缩为顶部封面。
- 折叠展开态：细轨可扩为 220px 带文字，双主角版式在窄屏改为上下堆叠（音乐卡在前）。

## 10. 与需求文档的对应

覆盖 UI-1 至 UI-8；阅读器完整主题（纸色 / 护眼 / 深色 / OLED / 跟随）对应 EB-7，排版对应 EB-6，进度写回与离线标记（"已离线"）对应 EB-9/EB-11；音乐部分对应 MU-1/MU-2/MU-3/MU-4（直连优先 + 码率策略在设置页）/MU-5/MU-6。

## 11. 复现方式

```powershell
pwsh docs/design/_src/render.ps1 -Only home,detail,player,music,settings,reader,reader-paper,phone,icon
```

源文件：`docs/design/_src/direction-c.html`；素材与裁剪脚本同 A/B 方向。

## 12. 已知取舍

- 暖色暗调对内容图（偏冷色的海报）有轻微打架风险：落地时需要给图像加 5% 暖色叠加（`mix-blend-mode: soft-light`）统一色温。
- 阅读器使用宋体，需确认可分发字体许可（思源宋体 OFL）或改用系统宋体，避免 GPL 项目内的字体许可问题。
