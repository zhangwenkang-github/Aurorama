# 极光幕 · Aurorama 1.4.0 发布说明

> **已于 2026-11-02 发布**（tag `v1.4.0` + GitHub Release）。本文随发布材料补录入库。

## 关于本版本

极光幕（Aurorama）1.4.0：面向手机 / 平板的第三方原生 Jellyfin 客户端，基于 [Findroid](https://github.com/jarnedemeulemeester/findroid)（GPL-3.0）改造。本版在 1.3.0 基础上补齐下载控制、播放连续性与媒体信息、本地歌单、作用域搜索、持久缓存、离线身份和应用内更新，并收口 1.4.0 用户验收反馈。

包名 `io.github.zhangwenkang.aurorama`，版本 `1.4.0 (5)`，要求 **Android 9（API 28）及以上**；上一公开版本为 `1.3.0 (4)`。

## 本版亮点与修复

**下载与离线**

- **统一下载反馈**：批量下载可先受理再后台准备，状态细分到准备、连接、下载、校验、等待重试、暂停与失败；失败原因、重试次数和下次尝试时间可见。
- **批量与计数一致**：失败页支持全选重试，下载页、导航角标与通知统一未终态任务口径；`>99` 显示 `99+`，不再在图标旁挤压错位。
- **下载层级与动作**：进行中的具体任务优先展示，歌曲下载保持平铺，只有多曲专辑批次才使用容器；暂停、继续、删除和并发上限调整会即时反映到任务状态。
- **可恢复与防遗漏**：批量选择保持输入顺序，完成后再建任务不会因切换页面丢失余量；取消后可重新下载，迟到任务不得覆盖删除或恢复后的状态。

**音乐与歌词**

- **按点击顺序续播**：正在播放或暂停时点击歌曲只追加当前队列并播放新曲，不再重建或补齐整个浏览列表；“播放全部”仍会显式加载列表。
- **歌词刷新与跟随**：可刷新当前曲或当前可见列表的歌词；手动滚动后，滑回当前高亮行可恢复自动跟随。
- **本地歌单**：支持创建、改名、增删、排序与删除；提供版本化 JSON 完整备份，以及带 Aurorama 身份的 M3U8 兼容交换；同名导入生成副本，失效曲目保留占位。
- **队列恢复**：保存自然队列、当前曲、位置、播放模式与实际随机序；强制停止后可恢复顺序与后续曲目，但不会自动出声。

**播放与媒体信息**

- **画质档位**：采用 Jellyfin 官方 Android 客户端口径的 14 档画质，菜单同时显示分辨率标签与码率，包括 1.5 Mbps、720 kbps 和 420 kbps；分辨率标签不宣称服务端硬上限。
- **媒体详情**：视频详情显示源媒体宽高、码率、帧率与编码；播放面板显示当前实际流，未知值统一显示 `—`，切源后不串用旧值。
- **字幕优先级**：字幕语言、外观与延迟默认全局保存；单片手动选择或明确关闭只覆盖该片，并在切码率、切内核和重启后保持。
- **更稳定的 seek**：App 手势、进度条、章节与已接入的系统媒体控制统一经过请求、定位中、确认或失败状态；确认前不再闪现 0 或片尾，连续 seek 只采用最后目标。

**搜索、身份与缓存**

- **作用域搜索**：首页默认搜索全部；从视频、音乐或书籍进入时预设对应范围，并可在页内切换全部；从详情返回后保留查询、范围、结果与滚动位置。
- **来源隔离**：搜索结果按服务器 / 用户 / 本地库身份区分；只有可证明来源的下载副本才会折叠到服务器条目，不按标题猜测合并。
- **离线身份**：离线模式与 Jellyfin 用户会话分离，设置页可明确显示离线状态；没有可用用户时也能退出离线并返回登录。
- **先旧后新**：浏览、搜索、歌单摘要和封面可使用本地快照，断网时先显示旧内容，联网后在后台静默刷新；缓存按账号和服务器隔离，用户动作或切号可触发失效。

**应用内更新**

- **检查与下载**：支持手动检查，并在启动后最多每 24 小时自动检查一次稳定版 Release；按 ABI 优先选择 arm64，其他兼容设备使用 universal，下载残片可跨页面和进程恢复。
- **安装前校验**：下载完成后校验 SHA-256、包名、版本、签名与最低系统版本；只把符合条件的 APK 交给明确的系统安装器，拒绝静默安装、降级和跨签名覆盖。

## 安装与升级

从 GitHub Releases 下载与设备架构匹配的签名 APK，首次安装需允许“安装未知应用”。

| 下载文件 | 体积 | 面向 |
|----------|------|------|
| `Aurorama-1.4.0-universal.apk` | 172,997,968 B（164.98 MiB） | `armeabi-v7a` / `arm64-v8a` / `x86` / `x86_64`，兼容性优先 |
| `Aurorama-1.4.0-arm64-v8a.apk` | 79,415,990 B（75.74 MiB） | 仅 `arm64-v8a`，主流 64 位手机 / 平板 |

当前候选的 `versionCode` 从上一公开版本的 4 升至 5，且签名证书与 `v1.3.0` 相同；从上一公开版本升级时应选择同签名包覆盖安装并保留应用数据和登录态，该路径仍待当前 release APK 的最终设备验收。调试包（`.debug`）与正式包使用不同包名，可并存但数据独立。

> **不要用带有真实登录数据的 1.4.0 安装包回退到旧版本。** 本版使用更高的数据库 schema；旧包无法降级时可能触发破坏性迁移并清空本地服务器 / 用户数据。需要回归旧版时，应使用可丢弃的测试数据或单独的测试设备。

## 已知限制

- **当前核心验证覆盖 Pad + K60**（实测 API 33 / API 35），不是完整设备或系统矩阵 PASS；删除过渡、失败与运行并存、按压 / 待处理反馈、TalkBack、多行累计与跨刷新异常矩阵仍未全部执行。
- **签名双包最终设备验收为 PASS_WITH_GAPS**：当前签名双包已在 Pad `43af8627` / K60 `8e875894` 独立覆盖安装并完成核心发布链路、登录 / 数据保持与 0 App FATAL/ANR；系统 PackageInstaller 确认与 `1.3.0(4)→1.4.0(5)` 正向跨版本升级仍 NOT_RUN，用户最终发布验收待完成。
- **服务器歌单互通未开放**：本版只提供本地歌单及 JSON / M3U8 导入导出；服务器歌单互导与服务器写能力仍为后续能力，未向用户开放。
- **系统媒体与异常状态覆盖有限**：锁屏、蓝牙、车机及部分 mpv / HLS 异常重开路径未纳入本轮完整矩阵，不能据此宣称所有系统环境一致。
