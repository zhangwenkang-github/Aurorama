# 影阁播放界面规格（Player UI/UX Spec）

> 面向手机、平板、折叠屏、Android TV、车机、小窗、画中画与后台播放的完整播放界面规格。
> 技术栈：Kotlin + Jetpack Compose + Media3/ExoPlayer（+ libmpv 兜底、FFmpeg 软解）。
> 现状标记：✅ 已有 ｜ 🟡 部分 ｜ ⛔ 待做；分期：P0 本轮/立即 ｜ P1 下一轮 ｜ P2 依赖外部能力。

---

## 一、设计总原则

### 1. 五层结构

```
① 渲染层   PlayerView / mpv Surface —— 只出画面，不参与交互
② 手势层   单击 / 双击 / 长按 / 横向 / 纵向 / 双指 / 边缘 —— 只产出意图
③ 控制层   顶部栏 / 中央大控件 / 底部进度条 / 侧边按钮 —— 3~5 秒无操作自动淡出
④ 面板层   底部抽屉与弹窗：字幕、音轨、倍速、画面、音频、队列、剧集、弹幕、歌词、投屏、下载、信息、解码器、睡眠定时
⑤ 系统层   MediaSession / 通知栏 / 锁屏 / 耳机线控 / 蓝牙 / 音频焦点 / PiP / 后台 / TV 遥控 / 键盘
```

关键约束：手势层不直接改播放状态，只发 `PlayerIntent`；控制层纯展示；同一时刻只允许一个面板打开。

### 2. 视觉规范（影阁语言）

| 元素 | 规范 |
|------|------|
| 底色 | 视频外区域纯墨 `#0B0C0E`；控制层用渐变遮罩（上 `rgba(11,12,14,.85)→透明`，下 `透明→rgba(11,12,14,.92)`）保证文字可读 |
| 强调色 | 朱砂 `#D2553C` 只用于「当前可操作」：已播进度、选中项、主按钮 |
| 次级色 | 温灰 `#A8A49C`（未选中图标、时间文本） |
| 文字 | 宣纸白 `#F1EDE6`；标题 15sp、时间码 13sp 等宽数字 |
| 圆角 | 胶囊 999dp（按钮/进度条）、面板 16dp、卡片 12dp |
| 阴影 | 不用阴影，用 1dp `#24282C` 发丝线与明度差分界 |
| 命中区 | ≥48dp；进度条可点区高 ≥32dp（视觉 4dp） |
| 安全区 | 刘海/挖孔/手势条/圆角统一读 `WindowInsets`，控制层内容永远内缩 |

### 3. 状态与可达性

- 按钮八态：默认 / 按下 / 聚焦 / 选中 / 禁用 / 加载 / 激活 / 错误。
- 无障碍：图标按钮全部 `contentDescription`；TalkBack 顺序 = 顶部 → 中央 → 底部；支持大字体、高对比、键盘/遥控导航。
- 动效：控制层淡入淡出 150~200ms；进度条拖动 0ms 跟手；面板 250ms 上滑。

## 二、按键布局（按形态）

### 1. 竖屏（手机）

```
┌───────────────────────────────────────────┐
│ ← 标题 · 副标题 · S01E03 · 1080P   ⧉ ◫ ⋮ │  顶部栏
│                                            │
│              ⏮  ↺10  ▶/⏸  ↻10  ⏭          │  中央大控件（3~5s 淡出）
│         [缓冲圈 / 错误重试 / 跳过片头]      │
│                                            │
│  ─────────●──────────────  12:31 / 24:05  │  进度条 + 时间
│  ⏮ ↺10 ▶ ⏭ ↻10  1.0× 💬 🎧 ▭ ☰ ⋮        │  底部控制栏
├───────────────────────────────────────────┤
│ ▸ 选集 / 播放列表 / 简介（上滑展开）        │  竖屏专属内容区
└───────────────────────────────────────────┘
```

- 左缘竖滑 = 亮度，右缘竖滑 = 音量，画面区横滑 = 进度。
- 竖屏默认不自动旋转（用户手势或点击旋转按钮才转）。

### 2. 横屏（手机/平板）

```
← 标题 S01E03  1080P                        ⚙ ⋮      ← 顶部（左信息 / 右操作）
               ▶/⏸  ↺10 ↻10  ⏮ ⏭                    ← 中央
─ ─ ─ ─ ─ ─ ─ ─●─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─        ← 进度条（贴底）
⏮ ↺10 ▶ ⏭ ↻10 1.0× 💬 🎧 ▭ ⛶ ☰          🔒        ← 底部；右下角锁
```

- 左上有亮度/音量/进度/倍速提示浮层（半透明黑底、12dp 圆角）。
- 右下角按可用性显示：锁屏、截图、录制、AB 循环、弹幕、歌词。

### 3. 平板 / 折叠屏（展开）

- 主画面 + 右侧固定 320dp 侧栏（剧集 / 队列 / 简介），可一键折叠。
- 底部控制栏水平排布不横滑；进度条占满主画面宽度。
- 折叠屏半开（HALF_OPENED）：画面在上半屏，控制与剧集列表在下半屏。

### 4. 小窗 / 悬浮窗

只保留：播放/暂停、关闭、展开、细进度条；其余入口全部隐藏，避免误触。

### 5. 画中画（PiP）

- 只显示画面 + 系统三键（播放/暂停、上一集、下一集）。
- 进入 PiP 时控制层强制隐藏；恢复时不闪控制层；比例用 `setAspectRatio` 跟随视频。

### 6. Android TV（D-pad）

- 焦点框：2dp 朱砂描边 + 8dp 内边距；进入即聚焦「播放/暂停」。
- ←/→ 快退/快进 10s（长按连续），↑/↓ 在控制层内切换控件，OK 激活，BACK 逐级收起。
- 控制层常显；无操作 30 秒后降亮度并显示时钟。

### 7. 车机

- 大按钮（≥72dp）、高对比、单手可及；支持语音「播放/暂停/下一集/快进一分钟」。
- 行驶中禁用复杂面板；来电/导航播报自动暂停并降低音量。

### 2. 自动隐藏

- 播放中 3 秒（可配 3/5/10/永不）无操作淡出；暂停时不隐藏。
- 面板打开时控制层保持可见；拖动进度、双击、长按过程中计时器重置。

### 3. 防误触与安全区

- 锁屏后只保留锁按钮（可拖动），其余触摸吞掉；双击或上滑解锁。
- 亮度/音量手势只在边缘 25% 宽度内生效，避免与横向进度冲突。
- 安全区统一 `displayCutout + systemBars`；TV 端额外留 5% overscan。

## 五、状态机

### 1. 播放状态机

```
            ┌──────────┐
            │  Idle    │  进入播放页 / 解析 PlaybackInfo
            └────┬─────┘
                 ▼
            ┌──────────┐  首帧就绪   ┌───────────┐
            │ Loading  ├────────────►│ Buffering │◄─── 网络抖动
            └────┬─────┘             └─────┬─────┘
                 │ 失败                    │ 缓冲完成
                 ▼                         ▼
            ┌──────────┐             ┌──────────┐  用户暂停   ┌──────────┐
            │  Error   │             │ Playing  ├────────────►│  Paused  │
            └────┬─────┘             └────┬─────┘◄────────────┴────┬─────┘
                 │ 重试 / 切内核           │ 播放结束              │ 继续
                 ▼                         ▼                       │
            ┌──────────┐             ┌──────────┐                  │
            │ Retrying │             │  Ended   │── 下一集 / 退出 ◄─┘
            └──────────┘             └──────────┘
```

- 可并存的附加态：`Offline`（本地文件）、`Live`（直播）、`Drm`、`Ad`（广告倒计时/跳过）、`Background`、`Pip`、`Casting`、`HeadsetUnplugged`、`CallInterrupted`。
- 恢复策略：解码失败 → 自动软解 → 仍失败 → 提示换内核（mpv）；网络失败 → 指数退避重试 3 次后提示离线播放（有缓存时）。

### 2. 控制层状态机

```
Hidden ──单击 / 双击 / 遥控──► Visible ──3~5s 无操作──► Hidden
Visible ──锁按钮──► Locked ──双击 / 上滑──► Visible
Visible ──面板入口──► PanelOpen ──返回 / 下划──► Visible
```

## 七、验收标准

### 功能

1. 播放/暂停、快进 10s、快退 10s、上一集/下一集在竖屏、横屏、小窗、PiP 四种形态均可用。
2. 三种倍速入口一致：长按临时倍速、菜单常驻倍速、记忆上次倍速。
3. 字幕：切换语言后退出重进仍生效；延迟调整立即生效；双语模式两行不重叠。
4. 进度条拖动跟手（<16ms），松手 300ms 内画面追上；章节与片头/片尾标记可见。
5. 手势互不冲突：单击/双击/长按/横滑/竖滑/缩放；边缘手势只影响亮度/音量。
6. 锁屏后任何触摸都不改变播放状态，只有解锁按钮可交互。
7. 错误恢复：断网 3 秒内出现重试提示；解码失败自动降级并显示当前内核。
8. 后台：开启「后台继续播放」后锁屏 3 分钟音频不中断（前台服务落地后按 30 分钟验收）。

### 交互与体验

9. 控制层 3 秒淡出、触摸立即出现且不闪烁；面板打开时控制层不消失。
10. 遥控器 4 向键 30 次内可达任意控件，焦点框始终可见。
11. 图标按钮 ≥48dp，TalkBack 能读出含义；大字体下底部栏换行不截断。

### 性能

12. 进入播放到首帧 ≤1.5s（局域网直连）；切分辨率 ≤2s。
13. 控制层显隐不掉帧；播放中控制层带来的额外耗电 <3%。
14. 连续播放 2 小时内存增长 <80MB，无 ANR。
